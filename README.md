Entry for the make.fun bounty [Tell a Whole Story in 32 Characters](https://make.fun/b/u-xvader-tell-a-whole-story-in-32-characters-f86dd978?utm_source=github&utm_medium=readme&utm_campaign=story-in-32-characters).

`main.py` writes the Wi-Fi network name to `/output/entry.txt`:

> MyDogIsFamous_ImStaff

The name was picked by duelling a dozen drafts against the competition's
published judge brief (joke first, then the whole story it implies, then
freshness and tight wording), and the champion was then duelled against
the strongest names in the live field in both orders. The full draft
list and duel record are in [candidates.md](candidates.md).

## Run

```sh
python3 main.py   # writes /output/entry.txt and prints the name
```
